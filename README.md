# NirmanTools BD v3 — SEO Growth Edition

Static Bangladesh construction calculator + knowledge hub.

## Included
- Existing calculator tools from v2
- 30+ Bangladesh-specific supporting SEO guides
- Internal linking between calculators and guides
- Self-referencing canonical URLs
- WebPage JSON-LD on guide pages
- Expanded sitemap with lastmod
- robots.txt with sitemap
- Mobile-first design and zero backend

## Vercel
1. Upload the `NirmanToolsBD` folder to GitHub.
2. Import the repo into Vercel.
3. Framework: Other / no framework.
4. Build command: empty.
5. Output directory: `.`
6. Deploy.
7. IMPORTANT: replace `YOUR-VERCEL-DOMAIN.vercel.app` in every HTML canonical URL, `robots.txt`, and `sitemap.xml` with your actual Vercel domain.

## SEO launch checklist
- Verify the site in Google Search Console.
- Submit `/sitemap.xml`.
- Inspect the homepage and several guide URLs.
- Add a real About/contact page and clear editorial ownership.
- Replace any illustrative material rates with your own current supplier/market data before calling them current prices.
- Avoid publishing near-duplicate pages just to target keywords; each guide should solve a distinct user problem.

## Important
All construction estimates are preliminary. Structural design, reinforcement, soil decisions and safety-critical quantities should come from qualified professionals and approved drawings.
